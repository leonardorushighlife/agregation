# Инструкция по сборке Virtual Aggregation в EXE

Для того чтобы собрать скрипт `virtual_aggregation.py` в один исполняемый файл (.exe), выполните следующие шаги:

## 1. Установка необходимых библиотек
Убедитесь, что у вас установлен Python и библиотека `pyinstaller`. Если она не установлена, выполните команду в консоли:

```bash
pip install pyinstaller
```

## 2. Сборка EXE
Выполните следующую команду в папке с проектом:

```bash
pyinstaller --noconsole --onefile virtual_aggregation.py
```

### Пояснение флагов:
* `--noconsole` (или `-w`): При запуске программы не будет открываться черное окно консоли.
* `--onefile` (или `-F`): Все зависимости и сам скрипт будут упакованы в один единственный `.exe` файл.

## 3. Результат
После завершения процесса в папке проекта появятся новые директории. Ваш готовый файл будет находиться в папке `dist`:
`dist/virtual_aggregation.exe`

Эту папку `dist` можно переименовать или скопировать файл `.exe` в любое удобное место. Папки `build` и файл `.spec` можно удалить после успешной сборки.
