# Инструкция по сборке EXE

Для того чтобы собрать скрипт виртуальной агрегации в один исполняемый файл (.exe), выполните следующие шаги:

1. Установите PyInstaller (если еще не установлен):
   ```bash
   pip install pyinstaller
   ```

2. Выполните команду сборки в терминале (находясь в папке со скриптом):
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

3. После завершения сборки, готовый файл появится в папке `dist/virtual_aggregation.exe`.

### Особенности скрипта:
- **Интерфейс**: На русском языке.
- **Входные данные**: TXT файлы с кодами (поддерживаются кодировки UTF-8, CP1251, UTF-16).
- **Результат**: Новая папка с отдельными TXT файлами для каждого набора.
- **Безопасность**: Коды, содержащие недопустимые для имен файлов символы, автоматически очищаются.
