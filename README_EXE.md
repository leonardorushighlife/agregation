# Инструкция по сборке в EXE

Для создания автономного исполняемого файла (`.exe`) из скрипта `virtual_aggregation.py` рекомендуется использовать библиотеку `PyInstaller`.

## Шаг 1: Установка PyInstaller

Если у вас не установлен `PyInstaller`, установите его с помощью `pip`:

```bash
pip install pyinstaller
```

## Шаг 2: Сборка исполняемого файла

Запустите следующую команду в терминале (командной строке) в папке со скриптом:

```bash
pyinstaller --noconsole --onefile virtual_aggregation.py
```

### Описание параметров:
* `--noconsole` — при запуске приложения не будет открываться черное окно консоли (только графический интерфейс).
* `--onefile` — все зависимости и сам скрипт будут упакованы в один единственный `.exe` файл.

## Шаг 3: Результат

После завершения сборки:
1. Исполняемый файл `virtual_aggregation.exe` появится в папке `dist`.
2. Временные файлы сборки будут находиться в папках `build` и `virtual_aggregation.spec` (их можно удалить после проверки работоспособности EXE).

---
**Примечание:** Сборку рекомендуется производить на той версии Windows, на которой планируется использование программы.
