# Инструкция по сборке в EXE

Для сборки скрипта виртуальной агрегации в один исполняемый файл (.exe) выполните следующие шаги:

1. Установите PyInstaller, если он еще не установлен:
   ```bash
   pip install pyinstaller
   ```

2. Выполните команду сборки в терминале (находясь в папке проекта):
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

### Описание флагов:
- `--noconsole`: При запуске программы не будет открываться окно консоли (только графический интерфейс).
- `--onefile`: Все зависимости и сам скрипт будут упакованы в один единственный .exe файл.

После завершения сборки готовый файл появится в папке `dist`.
