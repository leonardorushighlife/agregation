# Инструкция по сборке EXE

Для сборки скрипта виртуальной агрегации в один исполняемый файл (.exe), выполните следующие шаги:

1. Установите `pyinstaller`, если он еще не установлен:
   ```bash
   pip install pyinstaller
   ```

2. Выполните команду сборки в терминале (находясь в папке проекта):
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

### Описание флагов:
* `--noconsole`: Отключает появление консольного окна при запуске приложения (так как у нас GUI).
* `--onefile`: Упаковывает всё приложение и его зависимости в один `.exe` файл.

После завершения сборки, готовый файл появится в папке `dist/virtual_aggregation.exe`.
