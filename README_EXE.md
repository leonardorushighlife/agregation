# Инструкция по запуску и сборке проекта "aggregation_LEONID"

Данная инструкция поможет вам запустить программу из исходного кода, собрать переносимый `.exe` файл для Windows 10/11 и настроить соединение (VPN/Proxy).

## 1. Подготовка окружения (Windows 10/11)

Для работы программы требуется **Python 3.8 или выше**.

1. **Установите Python**:
   - Скачайте установщик с [python.org](https://www.python.org/downloads/windows/).
   - При установке обязательно поставьте галочку **"Add Python to PATH"**.

2. **Скачайте исходный код**:
   - Распакуйте архив с программой в удобную папку (например, `C:\apps\aggregation_LEONID`).

3. **Установите зависимости**:
   - Откройте терминал (PowerShell или Командную строку) в папке проекта.
   - Выполните команду:
     ```bash
     pip install -r requirements.txt
     ```

## 2. Запуск из исходного кода

Чтобы запустить программу без сборки в `.exe`, используйте команду:
```bash
python main.py
```

## 3. Сборка в EXE файл

Для создания одного исполняемого файла, который можно переносить на другие компьютеры без установленного Python:

1. Убедитесь, что `pyinstaller` установлен (он входит в `requirements.txt`).
2. В терминале в папке проекта выполните команду:
   ```bash
   pyinstaller --noconfirm --onefile --windowed --name "Aggregation_App" main.py
   ```
   - `--onefile`: собирает всё в один `.exe`.
   - `--windowed`: при запуске не будет открываться черное окно консоли.
   - `--name`: задает имя файла.

3. После завершения процесса готовый файл появится в папке **`dist/`**.

**Важно**: Перенесите вместе с `.exe` файлом примеры Excel (`агригация пример .xlsx`), если они требуются для работы.

## 4. Настройка VPN / Прокси

Если в вашем регионе заблокированы сервисы (например, Telegram), вы можете настроить прокси прямо внутри программы:

1. Запустите программу.
2. На экране выбора языка нажмите на иконку шестеренки **⚙** в правом верхнем углу.
3. Введите пароль администратора (по умолчанию: `28091987`).
4. В нижней части панели вы увидите раздел **--- Proxy / VPN ---**:
   - **Proxy Host:Port**: введите адрес вашего прокси сервера (например, `127.0.0.1`) и порт (например, `1080`).
   - **User:Pass**: если прокси требует авторизации, введите логин и пароль.
   - Поставьте галочку рядом с полем Host:Port, чтобы активировать прокси.
5. Нажмите **Save**. Программа перезагрузит настройки и будет использовать прокси для всех сетевых запросов.

## 5. Требования к Windows 10/11

- **Разрешение экрана**: Рекомендуется не менее 1280x720.
- **Драйверы сканера**: Сканер должен работать в режиме эмуляции клавиатуры.
- **Язык**: Для корректной работы сканера раскладка клавиатуры в системе должна быть **Английская (English)** в момент сканирования.
