# Инструкция по использованию программы агрегации "Честный ЗНАК"

## Обзор
Программа предназначена для агрегации кодов маркировки (КМ) в транспортные упаковки (короба).
- **Количество КМ в коробе:** по умолчанию 24 (настраивается в админ-панели).
- **Выходные форматы:** TXT (XML структура) и XLSX (Excel).
- **Особенности:**
  - Автоматическое удаление криптохвоста (AI 93).
  - Проверка дубликатов КМ и SSCC кодов.
  - Независимость от раскладки клавиатуры.
  - Автосохранение каждые 30 коробок.

---

## Требования
Для запуска программы необходим установленный **Python 3.10+**.
Установите зависимости:
```bash
pip install requests openpyxl pyinstaller
```

## Настройка Telegram-бота
Чтобы получать отчеты в Telegram, выполните следующие шаги:

1. **Создание бота:**
   - Найдите в Telegram бота `@BotFather`.
   - Напишите ему `/newbot`.
   - Следуйте инструкциям (нужно будет придумать имя и username бота).
   - В конце BotFather пришлет **API Token** (выглядит как `12345678:ABCdef...`). Скопируйте его.

2. **Получение Chat ID:**
   - Найдите в Telegram бота `@userinfobot`.
   - Напишите ему любое сообщение.
   - Он ответит вашим `Id` (число). Это и есть ваш **Chat ID**.
   - *Важно:* Сначала обязательно запустите своего созданного бота (нажмите "Start"), иначе он не сможет присылать вам сообщения.

3. **Ввод настроек:**
   - Откройте программу, перейдите в **Админ-панель** (шестеренка в углу, пароль `28091987`).
   - Введите Token и Chat ID в соответствующие поля и нажмите "Сохранить".

## Работа с программой

1. **Запуск:** Выполните `python main.py`.
2. **Админ-панель:**
   - Здесь настраивается размер короба, ИНН, GTIN и дополнительные поля для Excel (ТН ВЭД, Название продукта, Номер ДС).
   - Если стоит галочка рядом с полем, оно будет отображаться в Excel-отчете о нанесении.
3. **Начало смены:** Введите дату, рабочее место и имя.
4. **Процесс сканирования:**
   - Сканируйте 24 товара.
   - После 24-го товара программа попросит **SSCC код**.
   - Отсканируйте SSCC. Программа проверит его на дубликат, закроет коробку и **автоматически перейдет к сканированию товаров для следующей коробки**.
5. **Завершение:** Нажмите "Завершить смену" для финальной отправки файлов.

## Сборка в EXE
Для создания одного файла `.exe` выполните:
```bash
pyinstaller --noconsole --onefile --name "Aggregation_LEONID" main.py
```
Готовый файл появится в папке `dist/`.
