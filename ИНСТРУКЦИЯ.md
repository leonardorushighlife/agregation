# Агрегация и Склад (WMS) — ИНСТРУКЦИЯ

Программа предназначена для агрегации кодов маркировки (DataMatrix) в короба и паллеты, а также для управления складскими операциями (Приемка, Отгрузка, Возврат).

## Установка

1. Установите Python 3.10 или выше.
2. Установите необходимые библиотеки:
   ```bash
   pip install requests reportlab Pillow pyserial python-barcode cryptography
   ```

## Запуск

Запустите файл `main.py`:
```bash
python main.py
```

## Режимы работы

1. **Производство (Агрегация):**
   - Сканируйте коды единиц товара.
   - После заполнения короба (настраивается в Админ-панели) отсканируйте SSCC-код короба.
   - После заполнения паллеты (110 коробов по умолчанию) отсканируйте SSCC-код паллеты.
   - Кнопка **"Полупалет"** позволяет закрыть паллету досрочно.

2. **Складские операции:**
   - **Приемка:** Добавление новых кодов на склад.
   - **Отгрузка:** Списание кодов под конкретный заказ (требуется GTIN соответствие).
   - **Возврат:** Возврат ранее отгруженных кодов в статус "на складе".

## Настройки (Админ-панель ⚙️)

- Пароль по умолчанию: `28091987`
- Здесь можно настроить размер короба, паллеты и целевой GTIN для производства.

## Удаленное управление (Stealth ❤️)

- Нажмите 10 раз на иконку сердца (❤️) на экране выбора языка, чтобы открыть настройки Telegram.
- Введите Bot Token и Chat ID.
- Команды боту:
  - `block SERIAL` — заблокировать устройство.
  - `active SERIAL` — разблокировать устройство.
  - `order SERIAL заказ НОМЕР продукт ИМЯ кол-во ШТУК GTIN КОД` — добавить заказ на отгрузку.

## Особенности
- Программа работает корректно (принимает сканирование) только когда окно находится в фокусе.
- База данных хранится в папке `data/warehouse.db`.
- Отчеты и этикетки сохраняются в папке `output/`.
