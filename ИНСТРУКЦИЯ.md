# Полная инструкция к программе агрегации

## 1. Лимит работы (Безопасность)
В программе встроен счетчик времени. Через **180 дней** после первого запуска программа перейдет в "ограниченный режим". Это сделано для вашей безопасности и контроля использования ПО.

## 2. Страховка данных (Если выключили свет)
Программа "умная". Каждый раз, когда вы сканируете SSCC и закрываете коробку, данные **мгновенно** сохраняются в базу данных.
- Если ноутбук разрядился или выключили свет — просто запустите программу снова.
- Она предложит: **"Найдена незавершенная смена. Продолжить?"**.
- Нажмите **"Да"**, и вы продолжите работу ровно с того места, где остановились.

## 3. Страховка интернета
Если в конце смены интернет пропал:
- Программа сохранит файлы в папку `output`.
- Вы можете позже отправить их вручную или дождаться появления связи.

## 4. Настройка Многопользовательского режима (СЕТЬ)

Эта функция позволяет 10–20 сотрудникам работать в одной сети Wi-Fi, проверяя дубликаты по общей базе.

### Шаг 1: Настройка СЕРВЕРА (Главный компьютер)
Один компьютер (самый стабильный) должен быть назначен **Главным (Сервером)**.
1. Зайдите в **Админ-панель**.
2. Установите галочку: **"Использовать как сервер дубликатов"**.
3. Задайте **"Сетевой ключ доступа"** (например: `SKLAD_77`). Это пароль для подключения других ПК к базе.
4. Нажмите **Сохранить** и перезапустите программу.
5. **После перезапуска** на главном экране и в админ-панели появится IP-адрес этого компьютера. Сообщите его другим сотрудникам.

### Шаг 2: Настройка КЛИЕНТОВ (Другие ноутбуки)
1. Зайдите в **Админ-панель**.
2. Галочка "Использовать как сервер" должна быть **СНЯТА**.
3. Введите тот же самый **"Сетевой ключ доступа"** (пароль).
4. В поле **"IP сервера (ручной)"** введите адрес, который вы узнали на Шаге 1.
5. Нажмите **Сохранить** и перезапустите программу.

## 5. Особенности сканирования
1. **Строгая проверка GS1 DataMatrix**: Программа требует наличия скрытых символов FNC1 и GS.
   - Если программа выдает ошибку "Отсутствует FNC1", значит ваш сканер "съедает" эти символы.
   - **Диагностика:** Используйте кнопку "Диагностика сканера" в Админ-панели, чтобы увидеть, что именно передает ваш сканер.
2. **Настройка сканера**:
   - Большинство сканеров по умолчанию работают как "клавиатура" и не передают скрытые символы.
   - Вам нужно перевести сканер в режим **"USB-HID Control Character"** или **"USB Serial/COM Port"** (потребуется установка драйверов от производителя).
   - Инструкция к вашему сканеру содержит специальные штрихкоды для переключения этих режимов.
3. **Защита SSCC**: Коробка закрывается только кодом упаковки (начинается на **00**).

---

## 6. Проверка на дубликаты
Проверка идет по **ПОЛНОМУ** коду (включая криптохвост). Это гарантирует, что два товара с одинаковыми серийными номерами, но разными проверочными кодами, не будут считаться дубликатами.
Если дубликат найден, программа покажет, кто и когда его отсканировал.

## 7. Настройка Telegram (ПОШАГОВО)
1. Создайте бота через **@BotFather** и получите **TOKEN**.
2. Узнайте свой ID через **@userinfobot** (поле `Id`).
3. Введите эти данные в Админ-панели.

## 8. ГЛАВНЫЙ АДМИНИСТРАТОР (Управление лицензиями)
Теперь вы можете контролировать использование программы на всех компьютерах.
1. **Запуск сервера и панели:** Запустите `admin/dashboard.py`. Это приложение объединяет в себе сервер лицензий и панель управления. Оно должно работать на компьютере с постоянным IP-адресом (или доступным через интернет).
2. **Мониторинг:** В панели отображается список всех ID оборудования (HWID), их IP-адреса, имена компьютеров и время последнего запуска.
3. **Блокировка:** Если программа используется без разрешения, выберите её в списке и нажмите **"БЛОКИРОВАТЬ"**. При следующем запуске у пользователя появится сообщение о блокировке.
4. **Языки:** В правом верхнем углу панели управления можно переключить язык интерфейса (RU, ZH, AR, KU).

## 11. Подробная настройка сети
Для корректной работы проверки дубликатов и лицензий между разными компьютерами:
1.  **Статический IP:** Желательно назначить серверному ПК статический IP в настройках роутера.
2.  **Порты:** Убедитесь, что порты `8080`, `5555` и `5556` не блокируются антивирусом.
3.  **Ключ доступа:** Этот ключ должен быть одинаковым на сервере и всех клиентах.
4.  **License Server:** В настройках программы на клиентских местах URL должен быть вида `http://IP_СЕРВЕРА:8080`.

## 9. Версия для ANDROID (ТСД)
Приложение адаптировано для работы на смартфонах и терминалах сбора данных (Zebra, Honeywell и др.).
- **Сборка:** Используйте фреймворк `Kivy` и инструмент `Buildozer`.
- **Сканирование:** Поддерживается встроенная камера, USB-сканеры и аппаратные кнопки ТСД (через Broadcast Intent).
- **Файлы:** Все файлы из папки `android` должны быть упакованы в APK.

```bash
pip install requests openpyxl cryptography flask pyinstaller kivy
pyinstaller --noconsole --onefile --name "Aggregation_LEONID" main.py
```

## 9. ГЛОБАЛЬНЫЙ КОНТРОЛЬ (Лицензирование)
Система защищена уникальным ID оборудования (HWID).
-   Главный администратор может видеть все IP-адреса, где запущена программа.
-   Возможность удаленной мгновенной блокировки любого пользователя.
-   Подробности по настройке сервера лицензий читайте в файле `README_ADMIN.md`.

## 10. МОБИЛЬНАЯ ВЕРСИЯ (Android)
Приложение адаптировано для ТСД (Терминалов сбора данных).
-   Позволяет агрегировать товар прямо на складе без привязки к компьютеру.
-   Поддерживает аппаратные кнопки сканирования на Zebra, Honeywell и др.
-   Для сборки APK используйте файлы из папки `android`.

## 📦 Работа со Складом (WMS)

Режим склада активируется в Админ-панели («Включить режим склада»). После перезагрузки интерфейс упрощается и переводится на Русский язык.

### 1. Добавление заказов для отгрузки
Заказы передаются удаленно через Telegram-бота.
* **Команда**: `order СЕРИЙНЫЙ_НОМЕР НОМЕР_ЗАКАЗА`
* **Пример**: `order AGG-ABCD1234 550021`
* После отправки бот подтвердит получение заказа. Программа автоматически подгрузит его в список доступных для отгрузки. Серийный номер вашего ПК можно увидеть при запуске или в Телеграм-отчете.

### 2. Технология процесса
1. **Приемка / Агрегация**:
   * **Агрегация (Юниты)**: Используется для сборки банок в короба (24 шт).
   * **Агрегация/Приемка**: Используется для сборки коробов на палету.
   * Палета автоматически закрывается после 110 коробов. Для досрочного закрытия (полупалет) нажмите кнопку **«Собрать полупалет»**.
   * Все принятые коды сохраняются в складскую базу данных.

2. **Отгрузка**:
   * Выберите режим «Отгрузка» при начале смены.
   * Выберите нужный номер заказа из списка подгруженных заказов.
   * Сканируйте коды палет или отдельных коробов. Система проверит их наличие на складе и отметит как «отгруженные».
   * По завершении смены будет создан файл `отгрузка_ДАТА_ЗАКАЗ.txt` и отправлен отчет в Telegram.

3. **Резервное копирование**:
   * В Админ-панели можно указать «Backup Path» (Путь для бэкапа).
   * Все созданные отчеты будут автоматически копироваться в эту папку (например, на сетевой диск или в папку облачного хранилища), что гарантирует сохранность данных при блокировках Telegram.
