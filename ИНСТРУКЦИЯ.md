# Полная инструкция к программе агрегации

## 1. Лимит работы (Безопасность)
В программе встроен счетчик времени. Через **180 дней** после первого запуска программа перейдет в "ограниченный режим". Это сделано для вашей безопасности и контроля использования ПО.

## 2. Страховка данных (Если выключили свет)
Программа теперь "умная". Каждый раз, когда вы сканируете SSCC и закрываете коробку, данные **мгновенно** сохраняются в базу данных.
- Если ноутбук разрядился или выключили свет — просто запустите программу снова.
- Она предложит: **"Обнаружена незавершенная смена. Продолжить?"**.
- Нажмите **"Да"**, и вы продолжите работу ровно с того места, где остановились.

## 3. Страховка интернета
Если в конце смены интернет пропал:
- Программа сохранит файлы в папку `output/unsent`.
- Как только интернет появится и вы запустите программу снова (или завершите следующую смену), она **автоматически** дошлет старые файлы.

## 4. Настройка Telegram (ПОШАГОВО)

Чтобы данные уходили вам в телефон, нужно сделать 3 простых шага в самом Telegram:

### Шаг А: Создание своего бота
1. Откройте Telegram и в поиске введите **@BotFather** (у него должна быть синяя галочка).
2. Нажмите кнопку **Start**.
3. Напишите ему команду: `/newbot`
4. Он спросит имя бота. Напишите любое, например: `MoySkladBot`.
5. Он спросит "username" бота. Оно должно заканчиваться на `_bot`. Напишите, например: `super_sklad_2024_bot`.
6. Если имя свободно, BotFather пришлет сообщение с текстом **"Use this token to access the HTTP API:"**.
7. Ниже будет длинный код (цифры и буквы), например: `712345678:AAHk...`. **Это ваш TOKEN.** Скопируйте его целиком.

### Шаг Б: Получение вашего ID (куда слать файлы)
1. В поиске Telegram введите **@userinfobot**.
2. Нажмите **Start**.
3. Он мгновенно пришлет вам сообщение, где будет строка `Id: 123456789`.
4. Эти цифры — ваш **Chat ID**. Скопируйте их.

### Шаг В: Активация
1. Зайдите в своего нового бота (которого вы создали в шаге А) и нажмите кнопку **Start**. **ЭТО ОБЯЗАТЕЛЬНО**, иначе бот не сможет вам писать.

## 5. Ввод настроек в программу
1. Запустите программу.
2. Нажмите на **шестеренку (⚙)** в углу.
3. Введите пароль: `28091987`.
4. Вставьте скопированный **Token** и **Chat ID**.
5. Нажмите **Сохранить**.

Теперь после нажатия "Завершить смену" вы получите отчет:
- Имя оператора.
- Сколько **полных коробов** собрано.
- Общее количество кодов.
- Все файлы (Excel и TXT).

## 6. Техническая часть
Установка зависимостей:
```bash
pip install requests openpyxl pyinstaller
```
Сборка в EXE (Windows):
```bash
pyinstaller --noconsole --onefile --name "Agregacia" main.py
```
