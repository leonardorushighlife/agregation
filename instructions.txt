ИНСТРУКЦИЯ ПО ЭКСПЛУАТАЦИИ И СБОРКЕ ПРИЛОЖЕНИЯ AGGREGATOR

1. ТРЕБОВАНИЯ К ОКРУЖЕНИЮ
- Python версии 3.8 или выше.
- Установленные зависимости из файла requirements.txt:
  pip install -r requirements.txt

Основные библиотеки:
- tkinter: Интерфейс пользователя (встроено в Python).
- requests: Связь с сервером лицензий и Telegram/WeChat.
- openpyxl: Работа с отчетами Excel (XLSX).
- cryptography: Шифрование конфигурационных файлов.
- pillow: Генерация и обработка изображений этикеток.
- python-barcode: Создание штрихкодов Code128 для SSCC.
- pyserial: Поддержка сканеров, работающих через COM-порт.
- pynput: Фоновый перехват данных со сканера в режиме клавиатуры.
- opencv-python & pylibdmtx: Работа с камерой (режим Machine Vision).

2. ЗАПУСК ПРИЛОЖЕНИЯ
- Для запуска из исходного кода используйте команду:
  python main.py

3. СБОРКА В EXE ФАЙЛ
Для создания исполняемого файла для Windows:
1. Установите PyInstaller: pip install pyinstaller
2. Выполните команду:
   pyinstaller --noconsole --onefile main.py
3. Готовый файл появится в папке "dist/main.exe".

4. РЕЖИМ «АГРЕГАЦИЯ В НАБОРЫ» (SETS)
Данный режим предназначен для сборки наборов из нескольких юнитов с РАЗНЫМИ GTIN в одну упаковку, которая маркируется обычным DataMatrix кодом (как у юнита).

Инструкция по работе:
1. На начальном экране выберите режим "Sets" (или «Агрегация в наборы»).
2. Укажите количество вложений в одном наборе (например, 2 или 3).
3. Заполните данные оператора и дату. Нажмите «Начать смену».
4. Сканируйте юниты (КИЗы). Программа будет принимать любые корректные коды GS1 DataMatrix, не требуя совпадения GTIN.
5. После сканирования заданного количества юнитов (например, 2), программа перейдет в режим ожидания кода набора.
6. Отсканируйте DataMatrix код, который будет наклеен на набор. Он должен быть валидным GS1 кодом и не должен был использоваться ранее как юнит или как код агрегации.
7. Программа закроет набор и позволит начать сборку следующего.

5. НАСТРОЙКИ (АДМИН-ПАНЕЛЬ)
- Вход в настройки осуществляется через иконку ⚙ (пароль по умолчанию: 28091987).
- В настройках можно включить режим склада (WMS), настроить прокси/VPN, параметры принтера и конвейера.

6. ПОДДЕРЖКА VPN / PROXY
Если требуется работа через прокси:
- В Админ-панели включите "Proxy Enabled".
- Укажите тип (SOCKS5/HTTP), хост и порт.
- Настройки сохраняются в зашифрованном виде в config_local.bin.
