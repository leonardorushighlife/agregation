ИНСТРУКЦИЯ ПО ЗАПУСКУ И СБОРКЕ ПРОЕКТА

1. ТРЕБОВАНИЯ
- Python 3.8 или выше.
- Установленные библиотеки: tkinter (обычно идет в комплекте с Python).

2. ЗАПУСК ИЗ ИСХОДНОГО КОДА
- Откройте терминал или командную строку в папке с проектом.
- Запустите программу командой:
  python main.py

3. СБОРКА В EXE ФАЙЛ
Для сборки используется библиотека PyInstaller.
- Установите PyInstaller, если он не установлен:
  pip install pyinstaller
- Выполните команду сборки в один файл без консоли:
  pyinstaller --noconsole --onefile main.py
- После завершения сборки готовый файл main.exe появится в папке "dist".

4. РЕЖИМ АГРЕГАЦИИ В НАБОРЫ
- Зайдите в панель администратора (шестеренка в углу, пароль по умолчанию: 28091987).
- Выберите режим "Sets (DM)".
- В этом режиме программа позволяет сканировать юниты с разными GTIN в один набор.
- По завершении наполнения набора (согласно размеру коробки/набора) программа потребует отсканировать DataMatrix код самого набора.
- Набор считается закрытым после сканирования его кода.
