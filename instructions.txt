ИНСТРУКЦИЯ ПО ЗАПУСКУ И СБОРКЕ (Версия с WMS, VPN и Наборами)

1. УСТАНОВКА ЗАВИСИМОСТЕЙ
Перед запуском убедитесь, что установлен Python 3.8+ и все необходимые библиотеки:
pip install -r requirements.txt

Основные библиотеки:
- requests (для сетевых запросов)
- PySocks (для работы через VPN/Proxy)
- openpyxl (для XLSX отчетов)
- cryptography (для шифрования конфига)
- pillow (для работы с изображениями этикеток)
- python-barcode (для генерации штрихкодов)
- reportlab (для PDF)
- pyserial (для USB-COM сканеров)
- pynput (для фонового перехвата сканера)

2. ЗАПУСК
Запустите главный файл:
python main.py

3. СБОРКА В EXE
Для сборки используется PyInstaller. Команда для создания одного файла без консоли:
pyinstaller --noconsole --onefile main.py

Готовый файл появится в папке "dist".

4. НАСТРОЙКА VPN / PROXY
- Зайдите в Админ-панель (пароль: 28091987).
- Найдите раздел "Proxy / VPN Settings".
- Включите "Proxy Enabled", выберите тип (SOCKS5 или HTTP), введите хост и порт.
- Нажмите OK для сохранения и перезапустите программу.

5. ОТПРАВКА ОТЧЕТОВ НА ПОЧТУ
- В Админ-панели настройте раздел "Email Settings (SMTP)".
- Укажите SMTP сервер (например, smtp.yandex.ru), порт (587), ваш логин и пароль.
- Введите Email получателя.
- При завершении смены отчеты (XLSX, CSV, XML) будут автоматически отправлены на указанный адрес.

6. РЕЖИМ АГРЕГАЦИИ В НАБОРЫ
- На экране начала смены выберите режим "Sets".
- В этом режиме можно сканировать юниты с РАЗНЫМИ GTIN.
- Когда набор наполнится, программа попросит отсканировать DataMatrix код самого набора.
- Набор считается закрытым после сканирования его кода.
