ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ virtual_aggregation.py

1. ТРЕБОВАНИЯ:
   - Установленный Python 3.x
   - Библиотека openpyxl (установка: pip install openpyxl)

2. ЗАПУСК СКРИПТА:
   - Откройте терминал (командную строку).
   - Перейдите в папку со скриптом.
   - Запустите командой: python virtual_aggregation.py

3. СБОРКА В EXE (ДЛЯ ЗАПУСКА БЕЗ PYTHON):
   - Установите pyinstaller: pip install pyinstaller
   - Выполните команду в папке со скриптом:
     pyinstaller --noconsole --onefile virtual_aggregation.py
   - Готовый файл появится в папке 'dist'.

4. ПОРЯДОК РАБОТЫ:
   - Выберите файл с кодами наборов (родители).
   - Выберите файлы с кодами вложений (дети). Можно выбрать несколько файлов сразу.
   - Укажите, сколько кодов брать из КАЖДОГО выбранного файла вложений на один набор.
   - Нажмите "Сформировать Excel файл" и выберите место сохранения.
