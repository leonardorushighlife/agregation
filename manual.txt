ИНСТРУКЦИЯ ПО ЭКСПЛУАТАЦИИ СИСТЕМЫ АГРЕГАЦИИ

1. ОБЩИЕ СВЕДЕНИЯ
Программа предназначена для агрегации кодов маркировки (Честный ЗНАК) в короба и палеты.
Поддерживаются два режима:
- Агрегация ЮНИТОВ в КОРОБ (01... -> 00...)
- Агрегация КОРОБОВ в ПАЛЕТУ (000... -> 001...)

2. ЗАПУСК И НАСТРОЙКА
- Запустите main.py (или собранный EXE).
- При первом запуске выберите язык интерфейса.
- В главном окне доступна кнопка ⚙ (наверху справа) для входа в Админ-панель (пароль 28091987).

3. АДМИН-ПАНЕЛЬ
- Размер короба: количество юнитов в одной коробке (по умолчанию 24).
- Строгая проверка GS1: если включена, программа требует правильную структуру DataMatrix.
- Режим сервера дубликатов: один компьютер в сети должен быть сервером, чтобы все остальные проверяли дубликаты через него.
- Сервер лицензий: адрес, где запущен admin/server.py (например, http://192.168.1.10:8080).

4. НАЧАЛО СМЕНЫ
Нажмите "Начать смену" и заполните данные:
- Дата производства.
- Номер рабочего места.
- Имя оператора.
- ВЫБОР РЕЖИМА:
    а) Короб (Юниты) - сканируете 24 товара, затем код коробки (00...).
    б) Палета (Короба) - сканируете заданное кол-во коробок (000...), затем код палеты (001...).

5. ПРОЦЕСС СКАНИРОВАНИЯ
- Программа принимает данные от 2D-сканера в режиме эмуляции клавиатуры.
- Раскладка клавиатуры не важна (программа сама переводит символы в латиницу).
- Если отсканирован дубликат, появится звуковой сигнал и ошибка.
- После заполнения контейнера (короба или палеты) программа ждет закрывающий код.

6. ВЫХОДНЫЕ ФАЙЛЫ (папка output)
- .txt (XML) - полная агрегация для Честного ЗНАКа.
- .xlsx - отчет в формате Excel.
- .csv - упрощенный отчет (только коды).

7. МОНИТОРИНГ (ADMIN)
- admin/dashboard.py: объединенная панель управления и сервер лицензий. Запустите этот файл на центральном ПК. Он автоматически начнет принимать запросы от клиентов и позволит управлять доступом. В самой панели можно переключать язык (RU, ZH, AR, KU) для удобства администратора.

8. ПОДРОБНАЯ НАСТРОЙКА СЕРВЕРА (ГЛАВНЫЙ ПК)
Для работы системы в многопользовательском режиме необходимо настроить Сервер:
1. Выберите один ПК, который будет всегда включен.
2. Узнайте его локальный IP адрес (например, 192.168.1.50). Это можно сделать в Админ-панели программы после включения режима сервера.
3. В Админ-панели ГЛАВНОГО ПК:
   - Включите "Использовать как сервер дубликатов".
   - Убедитесь, что "Сетевой ключ доступа" заполнен (это пароль для других ПК).
   - В поле "Сервер лицензий" введите: http://127.0.0.1:8080 (или IP этого же ПК).
4. На КЛИЕНТСКИХ ПК (другие ноутбуки):
   - В Админ-панели введите IP Главного ПК в поле "IP сервера (ручной)".
   - Введите тот же "Сетевой ключ доступа".
   - В поле "Сервер лицензий" введите URL Главного ПК: http://IP_ГЛАВНОГО_ПК:8080
5. Если связи нет, проверьте настройки Брандмауэра Windows (Firewall) — порты 8080 (лицензии), 5555 (TCP дубликаты) и 5556 (UDP поиск) должны быть открыты.

9. РАБОТА С ЗАКАЗАМИ (СКЛАД)
Для удаленной передачи заказов на склад используйте Telegram-бота:
1. Отправьте детальную команду:
   order СЕРИЙНЫЙ_НОМЕР заказ НОМЕР продукт НАЗВАНИЕ кол-во ЧИСЛО РЦ ГОРОД
   Пример: order AGG-ABCD1234 заказ 4525 продукт кола 0.33 кол-во 2640 РЦ Брянск
2. Программа автоматически рассчитает необходимое кол-во палет и коробок (1 пал = 110 кор = 2640 ед).
3. Оператор выбирает заказ из списка и видит прогресс сборки в реальном времени.

10. УДАЛЕННОЕ ОБНОВЛЕНИЕ
Для обновления программы отправьте боту:
update СЕРИЙНЫЙ_НОМЕР URL_НА_ZIP_АРХИВ
Программа скачает архив, распакует новые файлы (кроме папки data и конфигов) и предложит перезапуск.
