# Инструкция по настройке VPN / Proxy

В приложении реализована поддержка прокси-серверов (SOCKS5 и HTTP), что позволяет работать через VPN или защищенные туннели.

## Настройка через интерфейс

1. Запустите приложение.
2. На экране выбора языка нажмите на иконку шестеренки (⚙) в верхнем правом углу.
3. Введите пароль администратора (по умолчанию: `28091987`).
4. В открывшейся панели администратора прокрутите вниз до раздела **--- Proxy / VPN Settings ---**.
5. Установите галочку **Proxy Enabled**, чтобы активировать использование прокси.
6. Выберите тип прокси: **SOCKS5** или **HTTP**.
7. Введите данные вашего сервера:
   - **Host**: IP-адрес или доменное имя сервера.
   - **Port**: Порт сервера (например, 1080 для SOCKS5 или 8080 для HTTP).
   - **User** (необязательно): Логин, если прокси требует авторизации.
   - **Password** (необязательно): Пароль, если прокси требует авторизации.
8. Нажмите кнопку **Save**. Настройки будут применены немедленно.

## Ручная настройка (через конфиг)

Если интерфейс недоступен, настройки можно внести напрямую в файл `config_local.json` в корневой папке программы:

```json
{
  "proxy_enabled": true,
  "proxy_type": "SOCKS5",
  "proxy_host": "127.0.0.1",
  "proxy_port": "1080",
  "proxy_user": "myuser",
  "proxy_pass": "mypassword"
}
```

## Технические подробности

- Приложение использует библиотеку `PySocks`.
- После активации все сетевые запросы (через модуль `socket`) будут перенаправляться через указанный прокси-сервер.
- Для работы через VPN-клиенты (например, WireGuard или OpenVPN), работающие на системном уровне, настройка прокси в приложении обычно не требуется.

## Проверка работоспособности

1. Включите прокси в настройках.
2. Если прокси настроен неверно, приложение может работать медленно или выдавать ошибки при попытке отправки данных в конце смены.
3. Убедитесь, что ваш прокси-сервер активен и доступен с рабочего компьютера.
