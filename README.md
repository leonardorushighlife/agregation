# Инструкция по использованию программы агрегации "Честный ЗНАК"

## Обзор
Программа предназначена для агрегации кодов маркировки (КМ) в транспортные упаковки (короба).
- **Количество КМ в коробе:** 24 (настраивается в админ-панели).
- **Выходные форматы:** TXT (XML структура) для агрегации и XLSX (Excel) для отчета о нанесении.
- **Особенности:** Автоматическое удаление криптохвоста (AI 93), независимость от раскладки клавиатуры, дублирование проверок через SQLite базу.

---

## Требования
Для запуска программы необходим установленный **Python 3.10+**.

---

## Установка и запуск

1. **Установка зависимостей:**
   Откройте терминал (или командную строку) в папке с проектом и выполните:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск программы:**
   ```bash
   python main.py
   ```

---

## Работа с программой

1. **Выбор языка:** При запуске выберите нужный язык интерфейса.
2. **Админ-панель:**
   - Нажмите иконку шестеренки (⚙) в углу экрана выбора языка.
   - Пароль по умолчанию: `28091987`.
   - Здесь можно настроить: размер короба, ИНН организации (LP TIN), путь к базе данных, GTIN товара и настройки Telegram-бота.
3. **Начало смены:** Введите дату производства, номер рабочего места и имя оператора. Нажмите "Начать смену".
4. **Сканирование:**
   - Сканируйте 24 кода DataMatrix. Программа автоматически очистит их от криптохвостов.
   - После 24-го кода программа попросит отсканировать SSCC код короба.
   - После сканирования SSCC коробка закрывается, данные сохраняются, и цикл начинается заново.
5. **Завершение смены:** Нажмите "Завершить смену". Программа предложит сохранить данные и отправить их через Telegram (если настроен бот).

---

## Сборка в EXE (Windows)

Для создания исполняемого файла (.exe), чтобы программу можно было запускать без Python, выполните следующую команду:

```bash
pyinstaller --noconsole --onefile --name "Aggregation_System" main.py
```

- `--noconsole`: Программа будет запускаться без окна терминала (только GUI).
- `--onefile`: Все файлы будут упакованы в один .exe.
- `--name`: Название вашего файла.

После завершения сборки готовый файл появится в папке `dist/`.

## Файлы данных
- `data/duplicates.db`: База данных SQLite для проверки на дубликаты.
- `output/`: Папка, в которую сохраняются готовые отчеты TXT и XLSX.
- `config_local.json`: Локальные настройки программы.
