# Инструкция по сборке скрипта в EXE

Для того чтобы собрать скрипт `virtual_aggregation.py` в один исполняемый файл (.exe), выполните следующие шаги:

1. Установите PyInstaller (если он еще не установлен):
   ```bash
   pip install pyinstaller
   ```

2. Выполните команду сборки в консоли, находясь в папке со скриптом:
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

### Параметры команды:
* `--noconsole` — при запуске программы не будет открываться черное окно консоли (только графический интерфейс).
* `--onefile` — сборка всех зависимостей в один единственный .exe файл.

После завершения сборки готовый файл появится в папке `dist`.
