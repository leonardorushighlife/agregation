# Инструкция по сборке утилиты в EXE

Для создания исполняемого файла (`.exe`) из Python-скрипта `virtual_aggregation.py`, выполните следующие шаги:

## 1. Установка необходимых компонентов
Убедитесь, что у вас установлен Python, а затем установите библиотеку `pyinstaller`:

```bash
pip install pyinstaller
```

## 2. Сборка исполняемого файла
Запустите следующую команду в терминале (командной строке) в папке со скриптом:

```bash
pyinstaller --noconsole --onefile virtual_aggregation.py
```

### Описание параметров:
* `--noconsole`: При запуске программы не будет открываться черное окно консоли (только графический интерфейс).
* `--onefile`: Все зависимости будут упакованы в один единственный `.exe` файл.

## 3. Результат
После завершения процесса в папке появятся новые директории. Ваш готовый файл будет находиться в папке **`dist`**:
* `dist/virtual_aggregation.exe`

Этот файл можно переносить на другие компьютеры с Windows, установка Python на них не требуется.
