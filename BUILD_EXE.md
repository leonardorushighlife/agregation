# Инструкция по сборке EXE

Для того чтобы собрать скрипт виртуальной агрегации в один исполняемый файл (.exe), выполните следующие шаги:

1. Установите PyInstaller (если еще не установлен):
   ```bash
   pip install pyinstaller
   ```

2. Выполните команду сборки в терминале (из папки со скриптом):
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

3. После завершения сборки:
   - В папке `dist` появится файл `virtual_aggregation.exe`.
   - Этот файл можно переносить и запускать на других компьютерах с Windows.
   - Папки `build` и файл `virtual_aggregation.spec` можно удалить.

### Особенности скрипта:
- **Выбор файлов**: Вы можете выбрать один файл с кодами наборов и несколько файлов с кодами вложений.
- **Кодировки**: Скрипт поддерживает UTF-8, CP1251 (Windows-1251) и UTF-16.
- **Результаты**: Для каждой агрегации создается новая папка `aggregation_results_YYYYMMDD_HHMMSS`.
- **Имена файлов**: Коды наборов очищаются от запрещенных символов (типа `/`, `*`, `:`) для корректного сохранения в качестве имени файла.
