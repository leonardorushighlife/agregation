# Инструкция по сборке в EXE

Для сборки скрипта `virtual_aggregation.py` в исполняемый файл (.exe) используйте библиотеку `PyInstaller`.

### Шаг 1: Установка PyInstaller
Если он еще не установлен, выполните команду:
```bash
pip install pyinstaller
```

### Шаг 2: Сборка
Запустите следующую команду в терминале (в папке со скриптом):

```bash
pyinstaller --noconsole --onefile virtual_aggregation.py
```

### Пояснение флагов:
* `--noconsole` — при запуске приложения не будет открываться черное окно консоли.
* `--onefile` — собрать все зависимости в один единственный .exe файл.

После завершения сборки, готовый файл появится в папке `dist`.
