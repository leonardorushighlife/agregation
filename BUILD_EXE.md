# Инструкция по сборке в EXE

Для создания исполняемого файла (`.exe`) из скрипта `virtual_aggregation.py` выполните следующие шаги:

1. **Установите PyInstaller** (если еще не установлен):
   ```bash
   pip install pyinstaller
   ```

2. **Выполните сборку**:
   Откройте терминал в папке со скриптом и выполните команду:
   ```bash
   pyinstaller --noconsole --onefile virtual_aggregation.py
   ```

### Описание флагов:
- `--noconsole`: При запуске программы не будет открываться окно консоли (только графический интерфейс).
- `--onefile`: Все зависимости будут упакованы в один исполняемый файл.

После завершения сборки готовый файл `virtual_aggregation.exe` появится в папке `dist`.
