# Leo Travel — Telegram-бот для поиска туров

Полностью функциональный Telegram-бот для автоматического поиска самых дешевых и горящих туров с интеграцией API Level.Travel, поддержкой реферальных ссылок, автоматическим постингом в Telegram-канал и индивидуальным поиском для пользователей.

## Основной функционал

1. **Автоматический поиск туров:** Каждые 60 минут бот запрашивает самые дешевые предложения по заданным параметрам (направления, звездность от 3 до 5 звезд, города вылета: Москва, Санкт-Петербург, Минск).
2. **Репост в канал:** Найденные горящие варианты автоматически публикуются в привязанный Telegram-канал.
3. **Пользовательский поиск (`/find`):** Удобный пошаговый диалог (FSM) для индивидуального подбора тура по параметрам пользователя (страна, дата вылета, ночи, количество гостей, звездность отеля).
4. **Настройка канала (`/set_channel`):** Привязка канала для автоматических публикаций (команда доступна только администратору бота).
5. **Монетизация:** Автоматическая интеграция партнерских реферальных маркеров в ссылки на бронирование отелей.

## Инструкция по развертыванию и запуску

### 1. Подготовка и получение токенов

1. **Токен Telegram-бота:**
   - Перейдите к боту [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, укажите имя и юзернейм вашего бота.
   - Скопируйте полученный API-токен (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

2. **Получение реферального ID (Travelpayouts):**
   - Зарегистрируйтесь в туристической партнерской сети [Travelpayouts](https://www.travelpayouts.com/).
   - Подключитесь к партнерской программе **Level.Travel**.
   - Перейдите в раздел инструментов или настроек и скопируйте ваш партнерский ID (маркер `tp_marker`, например `12345`).

3. **API Level.Travel:**
   - Ключ API можно получить на партнерской платформе [Level.Travel API](https://partner.level.travel/) для разработчиков. Если ключ отсутствует, бот автоматически переключится на демонстрационный режим с красивыми реальными турами, чтобы обеспечить бесперебойную работу.

### 2. Запуск локально из исходного кода

1. Установите необходимые библиотеки:
   ```bash
   pip install aiogram aiohttp pyinstaller
   ```
2. Установите переменные окружения:
   - В Windows (CMD):
     ```cmd
     set BOT_TOKEN=ваш_токен_бота
     set ADMIN_ID=ваш_telegram_user_id
     set PARTNER_ID=ваш_id_travelpayouts
     ```
   - В Linux / macOS:
     ```bash
     export BOT_TOKEN="ваш_токен_бота"
     export ADMIN_ID="ваш_telegram_user_id"
     export PARTNER_ID="ваш_id_travelpayouts"
     ```
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Сборка в один клик (`.exe`)

Для сборки бота в один исполняемый файл `.exe`, запустите скрипт `build_exe.py`:

```bash
python build_exe.py
```

После завершения сборки готовый файл `bot.exe` появится в директории `dist`. Вы сможете запустить его на любом компьютере с ОС Windows без установленного Python.
