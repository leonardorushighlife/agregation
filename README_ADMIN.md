# ГЛАВНАЯ ИНСТРУКЦИЯ АДМИНИСТРАТОРА (Enterprise)

Данный документ описывает процесс полной настройки системы агрегации, включая управление лицензиями, сборку EXE и Android APK.

---

## 1. СТРУКТУРА СИСТЕМЫ

1.  **Основное приложение (Desktop):** Используется операторами для сканирования и агрегации.
2.  **Сервер Лицензий (`admin/server.py`):** Центральная база данных всех установок. Без разрешения этого сервера программа не запустится.
3.  **Панель Управления (`admin/dashboard.py`):** Программа для главного администратора (вас), где вы видите IP всех пользователей и можете блокировать их одной кнопкой.
4.  **Мобильная версия (`android/`):** Приложение для ТСД и смартфонов.

---

## 2. НАСТРОЙКА СЕРВЕРА ЛИЦЕНЗИЙ (ОБЯЗАТЕЛЬНО)

Чтобы вы могли контролировать программу, сервер должен быть запущен на компьютере, который доступен через интернет (или локальную сеть).

### Шаг 1: Установка зависимостей
```bash
pip install flask
```

### Шаг 2: Запуск сервера
Запустите файл `admin/server.py`. Он создаст файл `admin/clients.db`, где будут храниться все ID устройств.

### Шаг 3: Как сделать EXE для сервера
Если вы хотите запустить сервер как обычную программу:
```bash
pip install pyinstaller
pyinstaller --onefile admin/server.py
```
Готовый файл появится в папке `dist`.

---

## 3. ИСПОЛЬЗОВАНИЕ ПАНЕЛИ УПРАВЛЕНИЯ (DASHBOARD)

Файл `admin/dashboard.py` - это ваш пульт управления.

1.  **Поиск:** Введите часть IP или ID устройства в строку поиска, чтобы быстро найти оператора.
2.  **Блокировка:** Выберите строку в таблице и нажмите красную кнопку "БЛОКИРОВАТЬ". Пользователь сразу увидит сообщение: *"Свяжитесь с разработчиком"*.
3.  **Разблокировка:** Выберите заблокированное устройство и нажмите зеленую кнопку.

**Как сделать EXE для панели управления:**
```bash
pyinstaller --noconsole --onefile admin/dashboard.py
```

## 4. СБОРКА ANDROID APK (ДЛЯ ТСД)

Самый простой способ собрать APK - использовать бесплатный сервис **Google Colab** или локальную систему **Linux**.

### Метод через Buildozer:
1.  Установите Python зависимости: `pip install kivy`.
2.  Используйте файл `android/main.py`. **Важно:** скопируйте в папку `android/` файлы `gs1.py` и `state.py` перед сборкой.
3.  Создайте файл `buildozer.spec` (шаблон есть в папке проекта).
4.  Запустите сборку командой: `buildozer android debug`.

### Параметры ТСД (Zebra/Honeywell):
В настройках ТСД (DataWedge) укажите:
-   **Delivery Method:** Broadcast Intent
-   **Intent Action:** `com.symbol.datawedge.api.ACTION_BARCODE_DATA` (по умолчанию)
-   Программа в папке `android/main.py` уже настроена на прием этих сигналов.

## 6. ВОЗМОЖНЫЕ ОШИБКИ И РЕШЕНИЯ

| Ошибка | Причина | Решение |
| :--- | :--- | :--- |
| **"Доступ заблокирован"** | Устройство в черном списке | Разблокируйте HWID через `admin/dashboard.py` |
| **Задержка 30 сек** | Сервер дубликатов не найден | Проверьте Wi-Fi и IP сервера в настройках |
| **Не видит FNC1** | Сканер работает как клавиатура | Переведите сканер в режим COM-порта (инструкция к сканеру) |
| **APK не ставится** | Неизвестные источники | Разрешите установку из неизвестных источников в Android |
